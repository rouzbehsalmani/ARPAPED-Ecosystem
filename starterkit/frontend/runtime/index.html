client.log -- the frontend's own Bridge

This page runs its own Bridge Core entirely in the browser (bridge/core.js). client.log executes Local, right here, in this page's own JavaScript -- but it depends on log.write, which only exists on the backend, served separately (web.serve, an API only -- not this page). Clicking the button makes a real cross-origin HTTP POST to the backend's /bridge endpoint (executor_kind: remote) -- the text below the button is what came back from THIS page's own Bridge; the backend's own console/terminal is where log.write actually printed it.
